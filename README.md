# ArachnoPhonics

## Description
ArachnoPhonics shows the user a hangman like display with letter blanks 
underneath and asks the user to guess a letter. Depending on whether the user 
gets the letter right or not, the letter blanks will either be filled or a 
spider will slowly develop in a hangman like way. The goal is to guess all of 
the letters in the word.

## How to run
Open main.py in the sandbox and click Run. Choose your difficulty level and 
then guess a letter that could possibly be in the word.

## Features
- Difficulty Level
- Hangman Like Display
- Tries Limit
- Play Again Option
